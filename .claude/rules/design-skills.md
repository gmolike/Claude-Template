# Design-Skills Regel

## Impeccable Design-Suite (pbakaus/impeccable)

Verantwortlich: Designer Agent, Senior Frontend

| Skill               | Wann nutzen                              | Pflicht bei                         |
| ------------------- | ---------------------------------------- | ----------------------------------- |
| `/impeccable`       | Meta-Skill fuer Design/Redesign/Critique | Jeder umfassenden Design-Aufgabe    |
| `/audit`            | Anti-Patterns finden                     | Review von UI-Code                  |
| `/polish`           | Visuelles Fine-Tuning                    | Vor Uebergabe an PO                 |
| `/normalize`        | Design-System-Konsistenz                 | Nach neuen Components               |
| `/distill`          | Komplexitaet reduzieren                  | Wenn UI ueberladen wirkt            |
| `/bolder`           | Visuelles Gewicht erhoehen               | Wenn Design zu zaghaft              |
| `/quieter`          | Visuelles Gewicht reduzieren             | Wenn Design zu aggressiv            |
| `/colorize`         | Farbe strategisch einsetzen              | Bei monochromatischen UIs           |
| `/clarify`          | UX-Copy verbessern                       | Bei unklaren Labels/Errors          |
| `/delight`          | Micro-Interactions hinzufuegen           | Fuer memorable Experiences          |
| `/adapt`            | Responsive Anpassungen                   | Bei neuen Breakpoints/Plattformen   |
| `/extract`          | Components extrahieren                   | Wenn Patterns sich wiederholen      |
| `/critique`         | Design-Feedback geben                    | Bei Design-Reviews                  |
| `/harden`           | Edge-Cases absichern                     | Vor Production-Release              |
| `/optimize`         | Performance verbessern                   | Bei langsamen Animationen/Rendering |
| `/onboard`          | Onboarding-Flows gestalten               | Bei neuen User-Journeys             |
| `/teach-impeccable` | Einmalige Kontext-Konfiguration          | Bei Projekt-Setup                   |
| `/frontend-design`  | Production-Grade Interfaces              | Bei neuen Pages/Components          |
